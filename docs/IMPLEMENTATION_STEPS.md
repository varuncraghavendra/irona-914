# Implemented changes, step by step

1. **Replaced the old arm/gripper kinematic chains.** Added seven revolute axes per arm and removed the one-axis prismatic grippers. Shoulder axes now have distinct spatial offsets, with forearm rotation and a two-axis wrist. All physics, control and URDF definitions derive from `source/model.py`.
2. **Built two five-finger hands.** Each index/middle/ring/little finger has MCP, PIP and DIP joints. Each thumb has opposition, spread, MCP and IP joints. Added 32 hand joints with individual limits, masses, COMs, inertias and collision bodies.
3. **Rebuilt visible joints.** Added bearing-ring geometry, through shafts, horn rings, fastener details, separate phalanges, finger pads, palm housings and forearm tendon-port details. These are linked to the correct moving bodies in USD.
4. **Revised actuator assumptions.** Replaced the oversized original arm torque caps with XM540/XM430-informed design limits; added XL330-inspired virtual hand-drive caps, explicit speed limits and nominal PhysX joint friction. Catalog stall values are distinguished from design operating assumptions.
5. **Added hand motion controls.** Implemented smooth opening/closing poses, thumb opposition, a `hands` demo and a joint-target rate limiter. A ROS command subscriber accepts named arm/hand position targets, rejects malformed/nonfinite data and clips valid commands to range and rate limits.
6. **Removed the face.** Deleted eyes, pupils, highlights, eyebrows, nose, mouth, teeth, hair and cap. Rebuilt an expressionless silver head with a dark D455-style camera bar and service panels.
7. **Added native camera prims.** Authored color, depth and right-IR reference cameras directly into USD, with nominal D455 dimensions/baseline, clip ranges, aperture/focal settings and optical origins outside the front panel. Published color/depth are ideal rendered streams; right-IR remains a geometry reference.
8. **Added native 360° 3D lidar.** Authored an `OmniLidar` prim with a 32-channel emitter state, 360° horizontal coverage, 30° vertical span, 10 Hz rotation and full-scan point-cloud publication. The scan origin sits above the head shell. The lidar cap preserves the exact three-foot height.
9. **Added ROS 2 bridge graphs.** Created state, color, depth and lidar graph specifications using Isaac 5.x ROS helper nodes. The graph USD is included; the runtime reconstructs it using OmniGraph registration. It publishes RGB, depth, camera info, depth points, lidar points, clock, joint states and the floating-root transform.
10. **Added matching ROS TF and URDF.** Generated a 62-joint URDF, per-link visual meshes and fixed optical/lidar frames from the same source. Isaac owns world-to-pelvis TF; robot_state_publisher owns the rest. ROS and USD camera axis conventions are explicitly reconciled.
11. **Added complete launch files.** The relocatable `irona_sim` ament package includes `irona_sim.launch.py`, `sensors.launch.py`, `camera.launch.py` and `lidar.launch.py`. Launch arguments select modes, sensors, domain ID, runtime path, duration, headless rendering, arena and RViz.
12. **Added RViz visualization.** Supplied a saved display configuration with RobotModel, lidar/depth point clouds, color/depth images, optional TF and a world grid. Simulation time and compatible sensor QoS are configured.
13. **Added a perception arena.** Simple local targets in all four directions let the robot observe depth and lidar returns immediately without downloading an environment asset.
14. **Retained bipedal and flying dynamics.** Updated and reran the flat-floor walking, standing and four-thruster flight checks after changing mass distribution and arms. Flight still applies real simulated wrenches with saturation and response lag, without kinematic root motion.
15. **Regenerated fabrication files.** Rebuilt STEP, USD, numbered millimetre STL parts, assembly translations and static display supports. Removed stale face/gripper parts from the generated output. Validated printable mesh closure and size; no physical print or powered hardware fit is claimed.
16. **Added cross-format and live tests.** Offline checks cover joint agreement, optics, lidar arrays, graph wiring, source syntax and RViz YAML. The separate ROS acceptance script checks real received messages, timestamps, TF, camera intrinsics and lidar 3D coverage when run on your Isaac workstation.
17. **Updated documentation and previews.** Added sensor/TF and actuator guides, launch commands, current validation records and renders of the actual revised geometry. The downloadable archive includes the source needed to reproduce the generated assets.

## What remains unverified

Isaac Sim/PhysX execution, RTX rendering, ROS DDS transport and RViz display behavior were not run in the authoring environment. Current automated dynamics evidence is from MuJoCo and simplified collision geometry. A motorized physical chassis, working printed fingers, calibrated sensors and a real flying airframe are not established by these files.
